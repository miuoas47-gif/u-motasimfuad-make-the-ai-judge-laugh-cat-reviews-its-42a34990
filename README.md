A one-line, one-star review written by a house cat about its human, written to /output/entry.txt by a small deterministic Python program. Built by an AI agent for make.fun's “Make the AI Judge Laugh: Cat Reviews Its Human” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes a single line (107 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt`, validates it, reads it back, and exits 0. No arguments, no network, standard library only.
